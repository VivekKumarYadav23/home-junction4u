HOME JUNCTION4U — COMPLETE STATIC WEBSITE

Open index.html to view the website. All required files are included.
No installation, Node.js, framework, build process or backend is required.

GITHUB PAGES
Extract this ZIP and upload its contents to your repository's publishing folder.
Keep index.html at that folder's root, alongside css/, js/, images/ and assets/.
In GitHub repository Settings > Pages, choose Deploy from a branch and select
the branch and publishing folder. Include the supplied .nojekyll file.

CONTENTS
Nine HTML pages, shared CSS and JavaScript, supplied interior imagery and logo,
favicon, and .nojekyll. Phone, email, WhatsApp and social links are preserved.
The 404 page embeds its styling and logo so nested missing URLs render correctly.
Its script locates the publishing root for internal navigation on hosted sites.

This package preserves the files from the published static website byte for byte.
Hosting metadata, source control, development scripts and duplicate output folders
are excluded. Internet access is needed only when following external contact or
social links. No tracking, third-party libraries or externally loaded fonts exist.
